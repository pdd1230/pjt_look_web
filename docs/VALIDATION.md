## 4. 미검증 항목

1. **Windows Python 3.11에서의 설치/배치파일 실행**. 권장 환경은 명시했으나 여기서 실제 실행하지 못했다.
2. **실제 MySQL 서버 연결·저장·재시작 조회**. SQLAlchemy 구현과 MySQL DDL 컴파일은 있으나 실제 연결 테스트와 구분한다.
3. **브라우저 화면/클릭 전체 흐름**. 로컬 Uvicorn 서버 시작은 확인했지만 원격 브라우저에서 이 실행 서버로 연결되지 않아 시각적 QA를 완료하지 못했다.
4. **실제 사용자 카메라·권한 거부·5분 연속 사용·초당 3~5회 달성**. 프레임 API를 테스트했으며 실제 카메라 측정은 아님.
5. **실제 손 영상 2개 및 Windows MP4 코덱**. 합성 영상의 파이프라인을 검증했으며 실제 촬영 데이터는 별도 확인 필요.
6. **독립 사진 60장·손 없는 사진 10장·양손 정확도**. 준비 자료 부족으로 미측정.
7. 배포·로그인·멀티프로세스 운영·공개 서비스는 이번 구현/검증 범위에 없다.

검증 순서는 PC_CHECKLIST.md를 따른다. 위 미검증 항목을 실제 완료 전까지 합격으로 표시하지 않는다.

## 5. 구현상 한계

- 원본 임계값은 그대로 유지했으며 가림·측면·추정 관절 오류와 손 교차 시 슬롯 변경에 대한 정확도 보장이 없다.
- 영상 모든 프레임의 좌표·진단을 DB JSON에 저장하므로 DB와 파일 크기가 증가한다. 수업용 짧은 영상부터 사용한다.
- 영상 작업은 단일 프로세스 메모리 큐다. 서버 중단 후 자동 재개하지 않고 실패로 표시한다.
- 결과 MP4는 mp4v/일정 FPS이며 음성을 보존하지 않는다. 브라우저 미지원 시 내려받아 재생한다. 가변 FPS 원본은 개별 재생 시점이 달라질 수 있으므로 시간 정밀 실험에는 일정 FPS를 권장한다.
- 입력 목록은 최근 1,000개를 표시한다. 전체 예측/정답 CSV는 별도 내려받는다.
